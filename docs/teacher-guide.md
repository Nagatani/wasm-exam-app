# 講師向けガイド

クラスの準備、試験・問題・テストケース・解答例の作り方、成績の確認方法です。

## 前提

- 講師アカウントが必要です。新しく構築した環境では**最初にサインアップしたアカウントが自動で講師**になります（[README](../README.md#最初の講師アカウントの作成)）。2人目以降は「管理者メニュー」の「教員への昇格」で追加します（下記）。
- ログインすると教師ダッシュボード（`/teacher`、試験の一覧）が開きます。ほかの画面へは右上の **☰ メニュー**から移動します。

## メニュー（☰）

どの画面でも右上の **☰** を押すと、右側にメニューが開きます。背景・✕・`Esc` で閉じます。

| 区分 | 項目 | 内容 |
|---|---|---|
| ページ | ダッシュボード | 試験の一覧（`/teacher`） |
| | クラス管理 | クラスと受講者名簿の管理（`/teacher/courses`、下記「クラス」） |
| | 管理者メニュー | サービス状態・パスワード再発行・強制ログアウト・教員昇格など（`/teacher/admin`、下記） |
| 設定 | 表示テーマ | ライト／ダークの切り替え |
| | 設定（AI機能など） | 表示テーマと、このブラウザでの **AI作問サポート**の有効化・モデル削除（`/settings`） |
| | パスワードを変更 | 自分のパスワードの変更 |
| — | ログアウト | |

- 開いている画面の項目はハイライトされます。
- 問題編集・試験詳細の画面で**保存していない変更があるとき**にメニューから移動しようとすると、確認が出ます。
- 生徒のメニューは「ダッシュボード」「表示テーマ」「設定（AI機能など）」（**AIヒント**の有効化）「パスワードを変更」「ログアウト」です。受験中の問題画面からメニューで移動・ログアウトすると、**下書きを保存してから**移動します。

## 管理者メニュー

☰ →「管理者メニュー」（`/teacher/admin`）。日常の作問・採点では使わない管理用の機能です。

- **サービス状態**：DB と judge（採点・Java 実行を担うサーバー側の実行環境）の状態（正常／接続不可／無効）。30秒ごとに更新。Java の問題が「準備中」になるとき、提出が「採点中」のまま進まないときに確認してください（judge が止まっていても提出は失われず、復旧後に自動で採点されます）。
- **パスワードの再発行**：学籍番号を指定して生徒の初期パスワードを再発行します。クラスに所属していない生徒にも使えます。新しい初期パスワードが表示されるので本人に伝えてください。今のパスワードは使えなくなり、ログイン中の端末もすべてログアウトされ、ログイン失敗による一時ロックも解除されます。
- **強制ログアウト**：学籍番号を指定して、生徒をすべての端末からログアウトさせます。パスワードは変わりません。共用 PC でのログアウト忘れなどに。受験中の生徒に行うと、下書き保存していない編集は失われることがあります。
- **教員への昇格**：既存のアカウントを学籍番号で指定して教員にします。教員はすべての試験の編集・成績の閲覧ができるので、学籍番号をよく確認してください。
- **開発・動作確認**：サンドボックス（言語の実行を単体で試す開発用ツール）へのリンク。

パスワードの再発行と強制ログアウトは、教員アカウントには使えません。

## クラス（受講者名簿）

☰ →「クラス管理」から、クラス（授業・クラス分け）を作って受講者を登録します。

- クラス名・学期（任意）で作成します。
- クラスを開くと受講者一覧と2つの追加欄があります。
  - **新規：生徒アカウントを一括作成**：1行に「学籍番号,氏名」で貼り付け（CSV 可、「ファイルから読み込む」も可）。既存の学籍番号はスキップされます。作成した各アカウントには**ランダムな初期パスワード**が発行され、作成後に**初期パスワード一覧の印刷用ウィンドウ**が開きます。作成したアカウントはこのクラスにも登録されます。
  - **既存：受講者を追加**：学籍番号を1行ずつ、または CSV を貼り付け（各行の先頭列を学籍番号として読む）。アカウントがある学生だけが登録され、見つからない学籍番号は結果に表示されます。
- 初期パスワードは、生徒が初回ログインで自分のパスワードに変更するまで受講者一覧に 🔑 で表示され、「初期パスワード一覧を印刷」で再印刷できます。**生徒が変更した時点で初期パスワードは無効・非表示になります。**
- **パスワードを忘れた生徒**は、受講者一覧の「パスワード再発行」で復旧できます。新しい初期パスワードが 🔑 に表示されるので本人に伝えてください。生徒は次回ログイン時にパスワードの変更を求められます。今のパスワードは使えなくなり、**ログイン中の端末もすべてログアウトされる**ので、受験中の生徒は再ログインが必要です。ログイン失敗でロックされた生徒も、これで解除されます。
- パスワードは変えずに**ログアウトだけさせたい**ときは「ログアウトさせる」を使います。
- 受講者は「削除」で外せます（アカウントは残ります）。
- **試験にクラスを指定**すると、その試験は**そのクラスの受講者だけ**に表示され、受験できます（指定しない試験は全生徒に公開）。成績の一覧・CSV も、そのクラスの受講者だけになります。
- クラスを削除しても試験は残ります（クラス指定が外れ、全生徒に公開されます）。

## 全体の流れ

```
試験を作る（非公開）
  └─ 問題を追加する
       ├─ 解答言語を選ぶ
       ├─ 問題文を書く
       ├─ 初期テンプレートコードを用意する
       ├─ テストケースを追加する（サンプル / 非公開）
       └─ 解答例コードを登録する（任意・生徒には非公開）
公開前チェックを確認して「公開中」にする  ← ここで初めて生徒に見えます
受験後、成績を確認 / CSV 出力する
```

## 1. 試験を作る

`/teacher` の「＋ 新規試験作成」から、タイトル・説明（任意）・**モード**・制限時間（分）・**受験可能回数**・**公開開始日時 / 受付終了日時**（任意）・**既定の解答言語**を入力して作成します。作成直後は **非公開（DRAFT）** です。

- **受験可能回数**は既定 **1回**で、任意の回数や「無制限」にもできます。複数回受験できる場合、**最後に提出した回の点数**が成績になります（最高点ではありません）。
- **既定の解答言語**は、この試験に新しく追加する問題の言語の初期値です。後から変えても既存の問題には影響せず、問題ごとに言語を変えられます。

### モード：試験 か 演習 か

作成時に選びます（後から試験詳細で変更も可能）。

| | 試験（EXAM、既定） | 演習（PRACTICE） |
|---|---|---|
| 用途 | 成績評価・確認テスト | 学習支援（テストの代わりには使わないでください） |
| 制限時間・受験可能回数・公開スケジュール | あり | **なし**（入力欄も表示されません） |
| 提出 | 1回の受験につき、下書き → 最終提出で確定（取り消し不可） | **何度でも**提出でき、毎回全テストケースで判定されて履歴に残る |
| 結果の確認 | 成績ダッシュボード・CSV | 「演習の状況」画面（点数ではなく取り組み状況） |
| AIヒント | 使えない | 問題ごとに許可できる（後述） |

演習モードの試験は、生徒ダッシュボードの「演習」欄に表示されます。問題の作り方は試験モードと同じです。

### 試験を複製する

教師ダッシュボードの試験一覧の「複製」で、既存の試験（モード・全問題・テストケース・解答例・タグ込み）を丸ごとコピーできます。コピーは必ず**非公開・公開スケジュール未設定**で作られます（誤って生徒に見えないように）。クラス指定と受験可能回数は引き継がれるので、必要なら調整してください。

## 2. 試験の設定と問題の追加

試験名をクリックすると試験詳細（`/teacher/exams/:examId`）が開きます。

- タイトル・説明・モード・制限時間・受験可能回数・既定の解答言語の編集
- **クラス**（任意）の指定
- **公開開始日時 / 受付終了日時**（任意、試験モードのみ）
- **公開ステータス**（非公開 / 公開中）の切り替え
- 「＋ 問題を追加」で問題を作成（問題編集画面に移動します）
- 「**問題バンクから追加**」で、自分の問題と、他の教師が「公開」にした問題を検索してこの試験に複製（タイトル・言語・タグ・公開範囲で絞り込み）。同じ画面の「JSONファイルからインポート」で、問題編集画面の「エクスポート」で書き出したファイルを取り込めます（別のサーバーとの共有やバックアップ用。インポートした問題は常に非公開で追加されます）
- 問題一覧の「複製」で、その問題（問題文・言語・テンプレート・配点・比較設定・テストケース・解答例ごと）をこの試験の末尾に複製
- 出題順は、各行の ⠿ をドラッグするか ▲▼ ボタンで並び替え（テストケースも問題編集画面で同様に並び替えられます）
- 「成績を見る」（試験モード）／「演習の状況を見る」（演習モード）

**制限時間**は、生徒がその回の受験を**開始した時刻**からのカウントダウンです。複数回受験の場合、回ごとに最初からになります。

**公開開始日時 / 受付終了日時**（講師の端末の時刻で入力）：

- 公開開始日時より前は、公開中でも受験を開始できません（「公開開始: 〜」と表示）。
- 受付終了日時を過ぎると新しい受験は開始できません。受験中の回は受付終了時刻で自動提出されます（各回の締切は「開始＋制限時間」と「受付終了日時」の早い方）。

## 3. 問題を編集する

問題編集画面（`/teacher/exams/:examId/tasks/:taskId`）は、「基本情報」「テストケース（行ごと）」「解答例」をそれぞれ別のボタンで保存します。未保存のセクションには「● 未保存」が付き、画面上部にも一覧が出ます。

### タイトル・表示順・配点

既定では、全テストケースが AC のときだけ配点が入ります。「**部分点を認める**」を有効にすると、通過したテストケース数（サンプル・非公開とも）に比例した点数を四捨五入で採点します。コンパイルエラーはどちらでも0点です。

### 解答言語

`C` / `Java` / `JavaScript` / `TypeScript` / `Python` から **1つ** 選びます。生徒はここで指定した言語だけで解答します。

言語ごとの入出力の書き方と制限は **[languages.md](./languages.md)** を確認し、**問題文に入出力形式を明記してください**（例：「1行目に整数 n が与えられる。n を2倍にして1行で出力せよ」）。

### AIで下書きを作成（AI作問サポート）

「解答言語」の下に「🤖 AIで下書きを作成」ボタンが表示されます（このブラウザで ☰ →「設定（AI機能など）」の「AI作問サポート」を有効にした場合のみ。初回は AI モデル〈約2.5GB〉をこのブラウザにダウンロードします）。

作りたい問題を一、二文で書いて「生成する」を押すと、問題文・初期テンプレート・テストケース・解答例の**下書き**が生成されます。期待される出力は AI に書かせず、生成された解答例を実際に実行して求めます（C/JS/TS/Python はブラウザ、Java は judge で実行。judge が使えないときだけ Java の期待される出力は空欄になるので、保存後に確認してください）。解答例で実行できなかった入力は除外されます。

**プレビューを確認して「この内容を反映する」を押すまで、何も保存されません**。反映後も、問題文・初期テンプレートは「基本情報を保存」、解答例は「解答例を保存」を押すまで未保存です（テストケースは反映時に追加されます）。内容を確認してから保存してください。

### 問題文（Markdown）

Markdown で書けます。**編集 / 分割 / プレビュー**を切り替えられます（分割は左に入力・右にプレビュー）。セキュリティのため HTML タグは表示されません。

「画像を挿入」で画像（PNG / JPEG / GIF / WebP、5MB以下）をアップロードすると、カーソル位置に `![]()` が挿入されます。アップロードした画像は URL を知っていれば誰でも閲覧できます（問題文の図版は公開情報として扱っています）。

### 出力の比較方法

テストケースの「期待される出力」と「実際の出力」の突き合わせ方を選びます（既定は「完全一致」）。

| 比較方法 | 内容 |
|---|---|
| 完全一致 | 前後の空白だけ除いて文字列比較 |
| 行末の空白と末尾の空行を無視 | 各行の行末の空白と、末尾の空行を無視 |
| 空行をすべて無視 | 上に加えて途中の空行も無視 |
| 数値を許容誤差付きで比較 | 空白区切りのトークンで比較し、数値は「許容誤差」以内なら一致（数値以外は完全一致） |
| 大文字・小文字を無視 | 行末の空白と末尾の空行を無視した上で、大文字小文字の違いも無視 |

厳しめの比較方法で不一致（WA）になった場合、生徒の画面に「空白や改行の違いの可能性があります」のような**大まかな**ヒントが出ることがあります（非公開テストでも期待される出力そのものは表示されません）。単純に答えが違う場合はヒントは出ません。

### AIヒント（演習モードの問題のみ）

「AIヒントを許可する（演習モード）」を有効にすると、**演習モードの試験のこの問題**で、生徒がブラウザで AIヒントを有効にしていれば段階的なヒントを使えます（試験モードの問題では何も起きません）。

「公開する最大段階」でヒントを何段階目まで出すかを決めます。ヒントは3段階です。

| 段階 | 内容 |
|---|---|
| ヒント1：着眼点 | どのあたりに注目すべきかという抽象的な指摘 |
| ヒント2：疑わしい箇所 | コードのどのあたりが疑わしいかの指摘（修正内容には触れない） |
| ヒント3：修正方針 | どう直せばよいかの考え方 |

> ⚠️ **ヒント3は、単純な問題では答えにかなり近い内容になることがあります**（AI への指示だけでは防ぎきれません）。自力で解かせたい問題では、「公開する最大段階」を1か2にすることを検討してください。

生徒は ☰ →「設定（AI機能など）」で AIヒントを有効にし（初回はモデル〈約2.5GB〉をダウンロード。講師の「AI作問サポート」とは別の設定です）、問題を一度「実行」して不正解になった後、ヒント1から順に開いていきます。

### タグ・問題バンクでの公開

「タグ（カンマ区切り）」は問題バンク検索の絞り込みに使えます。「問題バンクで公開する」をオンにすると、他の教師の問題バンク検索にもこの問題が表示されます（既定はオフ＝自分の検索にだけ表示）。これは検索に載るかどうかの設定で、問題を編集・閲覧できる範囲は変わりません（どの教師も全試験を編集できます）。

「エクスポート」で問題を JSON ファイルに書き出せます（別の試験・別のサーバーへのインポート用）。

### 初期テンプレートコード

生徒が問題を開いたときにエディタに入っているコードです。言語を選ぶとその言語のひな形が入ります。「基本情報を保存」で保存されます。

### テストケース

「＋ テストケースを追加」で行を足し、各行に次を入力して「このテストケースを保存」で保存します。

- **入力（stdin）**：プログラムの標準入力に渡す文字列
- **期待される出力（stdout）**：正解の標準出力（比較方法は上の「出力の比較方法」に従います）
- **サンプルかどうか**

| 種別 | 生徒に見える情報 |
|---|---|
| サンプル | 入力と期待される出力の**両方** |
| 非公開（サンプルでない） | 入力**のみ**（期待される出力はブラウザに送られません） |

**一括追加**：「一括追加」で複数のテストケースをまとめて貼り付けられます。ケースの区切りは `===` だけの行、入力と期待される出力の区切りは `---` だけの行、ケースの1行目を `@sample` にするとサンプルになります。「ファイルから読み込む」でこの書式のテキストファイル（.txt、2MBまで）を読み込むこともできます。内容を確認して「この内容で追加」を押すまで何も作成されません。

**Java の問題**では、テストケースごとに制限時間（100〜15000ms、既定2秒）とメモリ（16〜512MB、既定256MB）を設定できます。ほかの言語は固定値です（[languages.md](./languages.md#言語の一覧)）。

**既存の提出を再採点**：テストケースや期待される出力を直した後、このボタンで保存済みの全提出を現在のテストケース・比較設定で採点し直せます（判定と得点が上書きされます。judge が必要です）。

判定ルールの詳細は [languages.md の「採点のルール」](./languages.md#採点のルール) を参照してください。

### 解答例コード（任意）

模範解答を登録できます。**生徒には公開されません**。「解答例を保存」で保存します。

**「解答例でテストケースを検証」**：解答例を全テストケースで実行し、「期待される出力」と「解答例の出力」を並べて表示します（C/JS/TS/Python はブラウザ、Java は judge で実行。保存はされません）。

- すべて「一致」なら、期待される出力が解答例と整合しています。
- 「不一致」などの行では、解答例が正しいと確認できた場合に限り「**実際の出力を期待値にする**」でその場で上書きできます（すぐに保存されます）。

## 4. 公開する

試験詳細で公開ステータスを **公開中（PUBLISHED）** にすると、生徒のダッシュボードに表示されます。非公開の試験は生徒からは存在も分かりません。

公開前に、試験詳細の**「公開前チェック」**を確認してください。テストケース未登録・サンプルなし・配点0・比較方法と期待される出力の不整合・judge 未設定・日時の矛盾などを ⚠（要修正）／△（注意）で示します。judge が未設定だと、Java の問題は受験できないため ⚠、C / JavaScript / TypeScript / Python の問題はブラウザの実行結果で採点される（時間切れの自動提出では0点になる）ため △ になります（△ は試験モードのみ）。問題があっても公開はできますが、生徒が正しく受験できない可能性があります。

## 生徒側の流れ（参考）

生徒には言語の選択も、設問ごとの提出もありません。

### 試験モード

1. ダッシュボードで「受験する」を押すと、その回の受験が始まりカウントダウンが始まります（その試験で使う言語の実行環境の準備が終わるまで、ボタンは押せません）。
2. 各設問の「下書き保存」で解答を保存します（**採点はされません**）。設問間は自由に行き来でき、下書きは何度でも上書きできます。下書き保存前の編集もブラウザ内に控えられており、タブが落ちたり再読み込みしたりしても、同じブラウザで開き直すと「復元する」を選べます（復元後は下書き保存が必要です）。
3. 「試験を提出する」→「最終提出する」。押した時点で提出が確定し、全設問の下書きを**サーバー（judge）が採点**します。結果画面は「採点中です…」の後、通常は数秒で結果に切り替わります。**提出後の修正・再提出はできません。** 確認画面では、下書き保存していない編集が残っている問題に「保存していない編集あり」と表示されます。
4. 制限時間が切れると、その時点の下書きが**自動的に最終提出**され、同じように採点されます（生徒のブラウザが閉じていても採点されます）。採点は「実行」と同じ実行環境・同じ時間制限で行うため、「実行」で AC だった解答が本採点で別の結果になることは原則ありません。
5. 受験可能回数が残っていれば、結果画面の「もう一度受験する」で次の回を白紙から始められます。成績は**最後に提出した回**になります。

### 演習モード

「受験」も「下書き保存」もありません。

1. ダッシュボードの「演習」欄から演習セットに入り、問題を選びます。
2. 「実行（お試し）」で結果を確認します（**記録されません**）。
3. 「提出する」を押すと全テストケースで判定され、**提出履歴に記録**されます（何度でも提出でき、履歴は消えません）。過去の提出をクリックすると、そのときのコードをエディタに読み込めます。
4. 編集中のコードは**同じブラウザ内にだけ**控えられ、再読み込み後に「復元する」を選べます（24時間またはログアウトで消えます。別の端末には引き継がれません）。区切りのよいところで提出するよう生徒に案内してください。
5. 講師が許可していれば、AIヒントのパネルが表示されます。

## 5. 成績を確認する（試験モード）

試験詳細の「成績を見る」→ `/teacher/exams/:examId/results`。

- **対象の生徒全員**が並びます（クラス指定があればその受講者、なければ全生徒。受験していない生徒は「未提出」）。
- 各問題について、その生徒の**最後に提出した回**の判定（AC/WA/CE/TLE/MLE）・得点・提出日時。最後の回で提出しなかった問題は「未提出」で、WA とは区別されます。
- 合計点、受験（提出回数 / その生徒の上限）、受験開始から最終提出までの所要時間、打鍵数・貼り付け量など（打鍵・貼り付け・所要時間は生徒のブラウザからの申告値で、目安です）。
- 合計点の横に「**採点中**」と出ている生徒は、最新の提出を採点している最中です（通常は数秒。それまでは前回までの結果を表示します。再読み込みで更新されます）。
- 行を展開して「**提出コードと結果を表示**」を押すと、最後に提出した回の**ソースコード**と、テストケースごとの入力・期待される出力・実際の出力・判定・**実行時間**（非公開テストも含む）、打鍵数・貼り付け回数・解答時間が見られます。実行時間は判定には使っていない参考値です（C/JS/TS/Python の「実行」は生徒の端末で測った値、Java は JVM の起動を含むため数百ms 程度になります）。
- 2回以上提出している生徒は「**受験回: 1回目（10点） 2回目（0点）★**」のボタンで**過去の回の提出も確認**できます（★ が成績に採用されている最後の回）。

### 追加受験・時間延長

- **追加受験**列に回数を入れると、**その生徒だけ**受験可能回数が増えます（「もう1回受けさせる」。0で解除）。**これまでの提出・成績は残ります**。受験回数が無制限の試験では設定できません。
- **延長**列に分数を入れると、その生徒だけ制限時間（と、受付終了日時があればその生徒の締切）が延びます（配慮対応。0で解除）。受験前・受験中どちらでも設定でき、各回に効きます。受付終了日時を過ぎてからの新しい受験の開始はできません。

### CSV 出力

同じ画面から CSV をダウンロードできます。

- 列：`学籍番号,氏名,試験名,<各問題のタイトル…>,合計点,受験回数,提出日時,所要時間（秒）` の後に、問題ごとの解答時間・打鍵数が続きます。
- Excel で文字化けしないよう先頭に BOM が付きます。ファイル名は試験名です。

### 差し戻し（受験をなかったことにする）

成績画面から、特定の生徒のその試験の提出・受験記録（全回分）をすべて削除できます。次に生徒が試験を開くと1回目の受験として始まります。

これは**全記録の消去**で、取り消せません。記録を残したままもう1回受けさせたいだけなら、「追加受験」を使ってください。

## 6. 演習の状況を確認する（演習モード）

演習モードの試験詳細の「**演習の状況を見る**」→ `/teacher/exams/:examId/practice-stats`。点数ではなく**取り組み状況**を確認する画面です。

- 上部に「取り組んだ生徒 / 対象の生徒」「提出の総数」「全問正解した生徒」などの集計。
- **問題別**：各問題を正解した生徒 / 取り組んだ生徒の人数と提出回数（つまずいている問題が分かります）。
- **生徒 × 問題の一覧**：正解済みは「✓ 3回」（3回目までに正解）、未正解は「✗ 2回」、未着手は「-」。学籍番号・氏名で検索、「取り組んだ / 未着手」で絞り込み。
- セルを押すと、その生徒のその問題の**提出履歴**（各回の判定・点数・日時・コード）が表示されます。
- 対象の生徒は、クラス指定があればその受講者、なければ全生徒です。

## 受験画面のプレビュー

生徒用の画面（`/student/...`）は講師でも開けるので、受験画面をそのまま確認できます。ただし講師が「受験する」から**「最終提出する」まで進めると、講師自身の受験として記録されます**。確認は「実行」・下書き保存までにするか、後で差し戻しで消してください。

`/teacher/sandbox` は言語の実行を単体で確認するための開発用ツールです（受験の流れとは無関係）。
