# 講師向けガイド

試験・問題・テストケース・解答例の作り方と、成績の確認方法です。

## 前提

- 講師アカウントが必要です。最初の1人はDBで昇格させます（[README](../README.md#最初の講師アカウントの作成)参照）。2人目以降はアプリ内の講師昇格APIで対応できます。
- ログイン後、講師は自動で `/teacher`（講師ダッシュボード）に遷移します。

## 全体の流れ

```
試験を作る（非公開）
  └─ 問題を追加する
       ├─ 解答言語を選ぶ
       ├─ 問題文を書く
       ├─ 初期テンプレートコードを用意する
       ├─ テストケースを追加する（サンプル / 非公開）
       └─ 解答例コードを登録する（任意・生徒には非公開）
試験を「公開中」にする  ← これで初めて生徒に見えます
受験後、成績を確認 / CSV 出力する
```

## 1. 試験を作る

`/teacher` の「＋ 新規試験作成」から、タイトル・説明（任意）・制限時間（分）を入力して作成します。作成直後の公開ステータスは **非公開（DRAFT）** です。

## 2. 試験の設定と問題の追加

試験名をクリックすると試験詳細（`/teacher/exams/:examId`）に入ります。ここで:

- タイトル・説明・制限時間の編集
- **公開ステータス**（非公開 / 公開中）の切り替え
- 「＋ 問題を追加」で問題を作成（作成すると問題編集画面に移動します）
- 「成績を見る」で成績ダッシュボードへ

制限時間は、生徒がその試験を**最初に開いた時刻**からのカウントダウンです（一覧に表示された時点ではなく、受験画面に入った時点が起点）。

## 3. 問題を編集する

問題編集画面（`/teacher/exams/:examId/tasks/:taskId`）の各項目:

### タイトル・表示順・配点

配点は全テストケースACのときだけ入ります（部分点はありません）。

### 解答言語

`C` / `Java` / `JavaScript` / `TypeScript` / `Python` から **1つ** を選びます。生徒側に言語の選択肢はなく、ここで指定した言語だけで解答します。エディタのシンタックスハイライトと実行方式もこの選択で決まります。

言語ごとの標準入出力の作法・制限は必ず **[languages.md](./languages.md)** を確認し、**問題文に入出力形式を明記してください**（例: 「1行目に整数nが与えられる。nを2倍にして1行で出力せよ」）。

### 問題文（Markdown）

Markdownで書けます。「プレビュー」で表示を確認できます。セキュリティのため生のHTMLは無効です（`<script>` などは描画されません）。

### 初期テンプレートコード

生徒がその問題を開いたときにエディタへ最初から入っているコードです。選んだ言語のエディタで編集し、**問題フォーム下部の「保存」**（タイトル等と一緒）で保存されます。

### テストケース

「＋ テストケースを追加」で行を足し、各行に:

- **入力（stdin）**: プログラムの標準入力に流し込まれる文字列
- **期待される出力（stdout）**: 正解の標準出力（前後の空白を除いて完全一致で判定）
- **サンプルかどうか**（チェックボックス）

テストケースは**行ごとに独立した「保存」ボタン**で保存します（問題フォームの「保存」とは別）。

| 種別 | 生徒に見える情報 |
|---|---|
| サンプル | 入力・期待される出力の**両方** |
| 非公開（サンプルでない） | 入力**のみ**（期待される出力はブラウザに一切送られません） |

判定ルールの詳細は [languages.mdの「採点の共通ルール」](./languages.md#採点の共通ルール)を参照。

> テストケースごとの制限時間・メモリは、現状 **Javaでのみ**有効で、値はAPI経由でのみ設定できます（編集UIに項目はありません）。既定値（2秒 / 256MB）のままで運用してください。C / JS / TS / Pythonは言語ごとの固定値です。

### 解答例コード（任意）

模範解答を登録できます。**生徒には一切公開されません**（生徒向けAPIは解答例テーブルに触れません）。独立した「保存」ボタンで保存します。

## 4. 公開する

試験詳細で公開ステータスを **公開中（PUBLISHED）** にすると、生徒のダッシュボードに表示され受験できるようになります。非公開の試験は生徒からは存在も分かりません。

## 5. 成績を確認する

試験詳細の「成績を見る」→ `/teacher/exams/:examId/results`。

- **全 `STUDENT` アカウント**が行として並びます（その試験に触れていない生徒も「未提出」で表示）。
- 各問題について、その生徒の**最新の提出**の判定（AC/WA/CE）・得点・提出日時。
- 合計点、受験開始から最終提出までの所要時間、打鍵数・貼り付け量など（打鍵/貼り付け/所要時間は生徒のブラウザからの自己申告値で、`code` と同じ信頼度です）。
- 一度も提出していない問題の状態は「未提出」で、`WA` とは区別されます。

### CSV出力

同じ画面からCSVをダウンロードできます。

- 列: `学籍番号,氏名,試験名,<各問題のタイトル…>,合計点,提出日時,所要時間（秒）,…`
- Excelが日本語CSVの文字コードを誤判定しないよう先頭にBOMが付きます。
- ファイル名は日本語（試験名）に対応しています。

### 差し戻し（再受験させる）

成績画面から、特定の生徒の特定の試験について「提出をすべて削除し、受験開始時刻もリセット」できます。次にその生徒が試験を開くとカウントダウンが最初からになります。

提出は本来**不可逆**（取り消し・再提出不可）で、これが唯一その原則を破る操作です。誤操作に注意してください。

## 受験画面のプレビュー

生徒用のURL（`/student/exams/:examId/tasks/:taskId`）は講師でも開けるため、受験画面をそのまま確認できます。ただし**プレビューで「送信」すると講師自身の提出として記録されます**。確認は「実行」までに留めるか、後で差し戻しで消してください。

`/teacher/sandbox` は言語実行の単体確認用ハーネスです（本番の受験フローとは独立）。
